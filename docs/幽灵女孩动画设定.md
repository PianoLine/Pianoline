# 月下青瓷 · 幽灵女孩动画设定

[128 × 128 定稿原图](../interactive/art/celadon-ghost.png)是所有动作的起始帧和归位帧。缩略图展示的是她坐在玩家对面的常态。

![幽灵女孩常态](../interactive/art/celadon-ghost.png)

**关键词**　中性少女、安静直视、微侧身托腮、米白短发、青雾发尾、灰红圆瞳、蓝灰叠层披肩、圆扣与双弧银链、炭灰裸臂、渐红手掌、尖指甲。

## 固定造型

- **脸与头发**　头向画面左侧的手掌轻靠，目光看向玩家。半垂眼睑，深色圆瞳，虹膜略带灰红，常态嘴角平静。刘海斜过脸，两侧发梢向外翻卷。米白是头发的主色，雾青集中在末端，发束与主体相连。
- **手与姿势**　画面左手托脸、肘部着桌；另一条前臂从画面右侧横放桌沿，红色指尖靠近托腮的肘。两条手臂从短披肩下直接露出。炭灰肘部沿小臂经过暗梅红过渡到手掌，最亮的红色留给手部。指间留空，尖甲能从剪影辨认。
- **衣饰**　冷蓝灰披肩靠前后叠片和低亮度滚边区分层次。领口是一颗普通圆扣。银链独立垂在圆扣下，两道弧线、小珠和浅色坠饰在胸前汇合。

## 动作与灯光

- **待机、说话**　以托腮姿势为基准。眨眼改眼睑，说话改嘴型，停顿时闭嘴。敲桌只抬落横放之手的指尖，让肘部接触点稳定。
- **瞄准、受击**　拖牌瞄准沿身体和发梢的透明轮廓描边。命中时允许肩头后弹、人物随透视退远，结束后回到同一张常态。沿用牌桌现有的减少动态效果设置。
- **暗场**　常亮时，头发、皮肤和披肩承接环境光与左右烛火的暖色。随烛光变暗，两侧虹膜和双手逐渐泛红，指尖与掌心较亮，手腕的暗梅红缓缓收进炭灰前臂。嘴部和脸颊随环境一起变暗。光照和交互描边在显示时叠加，母版始终保留原色。

## 交付与验收

首页待机使用两张同步图集，每帧 128 × 128。九行分为睁眼、半闭和闭眼三组，每组各有三档呼吸姿态。五列是独立的指尖姿势。披肩约 3.5 秒起伏一次，托腮的头随肩轻动，肘部始终贴桌。每隔 5.2 至 9.6 秒有 65% 的机会敲一组，第一下抬得高，第二下轻敲后归位。

眨眼间隔随机在 2.85 至 6.5 秒之间，合上、短暂停留再睁开，合计约 0.2 秒。眼睑逐步遮住虹膜红光，双手继续跟随烛光与敲击动作。拖牌瞄准、受击和减少动态效果时使用睁眼常态。

验收时分别通过本机服务和双击 `index.html` 打开首页。首次进入就应能看见桌后的角色。两张图集都加载成功后才切换到待机动画；图集缺失时继续显示静态立绘。熄灭五根蜡烛后，检查眼睛与手部的红光仍与当前姿势对齐。

- 所有帧共用 128 × 128 透明画布、定稿的 20 色色板与固定原点。采样直接取自原 PNG。常态可见范围是 x=22–105、y=5–125（从 0 起算）；动作帧保留整张画布，不逐帧裁边。
- 在原尺寸检查眼神、指尖和双弧银链；用整数倍最近邻放大检查孤立杂色、半透明毛边和循环接缝。最后在电脑首页对照全亮、全暗和拖牌瞄准三个状态。
