# 烛光木屋互动首页

本机工作稿载入 `prototype/index.html`；正式首页载入 `interactive/index.html`。木屋、桌子、书架、窗外树林和烛台是实时绘制的低面模型。桌后的守望人使用逐帧像素立绘。互动区域四周融入全站的炭黑背景，烛火摇曳，近处道具随鼠标移动产生更明显的视差。牌名置顶居中，牌脚印有项目编号和类别。

## 操作

新开或刷新首页时，会从打乱的牌库中抽取三张不同的作品卡（不足三张时全部发出），手牌上限五张。点击牌库抽牌，把牌拖回牌库即可收牌。点击作品卡会抬起放大，随后插画扩展到全屏，再落到项目页封面位置。也可以直接把牌拖到幽灵身上。拖牌命中后，幽灵向后弹、镜头短震，再进入该项目详情。点击幽灵或气泡会随机切换闲聊台词。左侧的三维牌库按余牌数量显示厚度，抽牌时牌面抬起，放回时牌面翻转，沿桌面从右侧滑入牌库最底层。开场三张手牌从牌堆错开发出，落定后再依次提示牌库和桌铃。牌库旁的黄铜怀表会快速收回整手，与余牌和已用牌合并，表针回拨一圈、牌堆连续切牌三次，再错开发出三张。右侧的黄铜桌铃控制「回合结束」，按下后铃盖短暂摆动，再定位到首页动态区。

桌面靠近玩家的一侧有三个牌位，下方是一条带空心菱形的细横线。每格可暂放一张，桌上的牌持续显示彩色项目封面。将手牌拖到空位松开，牌会扬起亮面、短暂停顿，再扣上桌面。触桌时四角闪出金线，拍牌声后带一小段金属余音。点击桌上的牌可收回手中，手牌达到五张时留在原位。使用怀表重抽也会保留桌上的牌。

从项目或动态返回时，桌上的牌保留原位，手牌和牌库保持当前顺序，已经打出的牌暂时移出牌局，使用怀表时洗回。空手牌也会保留。同一标签页内会分别记住五根蜡烛的亮灭。点击「返回首页」或页首品牌时，内容先淡出，牌桌再从中央显现。浏览器后退到首页也会淡入，开启「减少动态效果」时直接返回。

## 角色与背景音乐

新进或刷新首页时角色为守望人。点击八角铜镜，暗金色雾门升起，遮住人物时从守望人、白色人偶、梦庭人偶中随机换到另一套皮肤。雾丝继续流动，整片雾逐渐淡去。从项目或动态返回时保留当前皮肤。换装时回到守望人的普通歌单。若正在播放专属歌单，原曲渐出，普通歌单第一首渐入。若已暂停则保持暂停，若已在普通歌单则保留当前进度。使用白色人偶时，点击右侧灰蓝色小册三次，切入她的歌单并从第一首渐入。梦庭人偶的歌单由右侧酒红色皮面书触发，同样需要点击三次。未满三次就换装会清零计数。顶栏控制开关与进度，留声机在当前歌单内随机循环。打开项目、查看动态、返回首页或使用浏览器后退，都会延续当前曲目、进度和播放顺序。若浏览器拦住播放，点击顶栏的「点击打开音乐」重试。

酒红色书的封面取自[《血源》PlayStation 商店封面](https://store.playstation.com/en-us/product/UP9000-CUSA00900_00-BLOODBORNE000000)，灰蓝色书的封面取自[《艾尔登法环 黑夜君临》标准版封面](https://de.store.bandainamcoent.eu/elden-ring-nightreign-digital-full-game-pc-standard-edition/)。两枚刻印各用 64 × 64 像素，人物在金框内居中。红书用栗棕色（#4D2712），蓝书用深棕色（#482816），月光处留白透出书皮。绘制时将顶部的夜空延伸至各自金框的上内沿，人物和月亮保留原有比例。猎人身后的低悬满月照出亚楠尖塔和街道，骑士上方的新月、星光与风暴弧线呼应远山。悬停时这两本书会往外多抽一段并稍微抬起，让封面露出木挡板。

## 牌面与照明

米白色牌面使用黑色描边，插图以七级墨色和稀疏刻线保留像素感。选中时，插图渐变为原版彩色封面，移开后恢复。怀表平放在牌库旁，选中时以表壳前缘为支点立起。

烛台上的三根蜡烛、桌边和窗边的两根蜡烛都能单独开关，选中有细黄边。火焰、光晕和附近物件的明暗同步变化。灯暗时，选中牌库、怀表或铃铛会引出一道顶光。手牌只提亮当前选中的一张，拖放、收牌和重抽时，牌背和纸边也随环境变暗。全部熄灭时，窗景、角色的红眼和双手在暗处最醒目。

也可以通过网站导航访问作品。系统启用减弱动态效果时，场景停止持续晃动和火焰动画，出牌使用缩短的过渡。

## 幽灵台词与触发条件

完整台词及触发条件见[《幽灵语录》](../docs/幽灵语录.docx)。

将手牌放到空位后，幽灵会随机说一句放牌台词。点桌上的牌并成功收回后，会随机说一句收牌台词。手牌已满时，牌留在桌上，收牌台词也只在之后成功收回时触发。

通过古镜换上白色人偶或梦庭人偶后，幽灵会说对应皮肤的台词。从项目或动态回到原装扮时，气泡保持收起。

点击卡牌时幽灵会说告别语。拖牌瞄准时幽灵亮起轮廓，松手命中随机造成 36–54 点伤害，幽灵向后弹。伤害只用于演出。命中后，从幽灵的位置翻开项目封面，再进入详情页。

## 修改位置

- `assets/site-content.js` 提供个人资料、项目、卡面图片与开发日志。日常修改可使用[内容编辑器](../editor.html)。
- `prototype/cabin-mesh.js` 构造场景的几何形体。`prototype/cabin-view.js` 控制视角、烛光、模型回弹和镜头震动，优先使用 WebGL，亦提供软件绘制。
- `prototype/ghost-idle.js` 控制呼吸、眨眼与敲桌，`prototype/skin-mirror.js` 负责换装。动画要求见[角色动画设定](../docs/幽灵女孩动画设定.md)。
- `prototype/prototype.js` 管理手牌、拖放、幽灵台词和页面跳转。`prototype/prototype.css` 控制牌面布局、窄屏排列和边缘渐隐。
- `assets/site.js` 将互动区嵌入首页，根据子页面报告的实际高度调整。修改卡片高度或下缘渐隐时，请同时测试双击本地文件和通过 HTTP 浏览这两种方式。
- `assets/export-site.js` 维护整站导出的文件清单。增加必需场景脚本或装饰素材时，也要更新清单。
