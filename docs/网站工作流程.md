# 编辑、预览与备份

## 打开编辑器

在仓库根目录启动本机静态服务。如果电脑上装有 Python，可以运行：

```sh
python -m http.server 8201 --bind 127.0.0.1
```

打开[本机编辑器](http://127.0.0.1:8201/editor.html)。以后使用相同的浏览器和地址继续编辑，浏览器草稿按地址和端口分别保存。只查看网站时，也可以直接打开仓库根目录的 `index.html`。

## 修改内容

- **首页与简介**可以修改姓名、职业方向、简介和技能标签。「职业下方短文」显示在职业方向和「浏览项目」之间，可以换行，留空会隐藏。简介正文显示在首页简介区。桌上的小幽灵会随机闲聊，台词和触发条件见[《幽灵语录》](../docs/幽灵语录.docx)。
- **项目作品**可以修改手牌和列表共用的标题、类别标签、缩略图，以及详情页的职责、截图和视频。缩略图留空时沿用项目封面。把新素材放入 `assets/media/`，填写从仓库根目录起算的相对路径，例如 `assets/media/forging-card.webp`。
- **开发日志**可以插入文字和图片并调整顺序。填写标题并勾选公开显示后，从草稿预览查看列表和文章。
- **联系方式、颜色与排版**用于更新公开链接、内容页强调色、项目列数、首页区块宽度和详情页宽度。

## 更新背景音乐

1. 把音频放进 `assets/media/music/守望人/`、`assets/media/music/白色人偶/` 或 `assets/media/music/梦庭人偶/`。音乐根目录里的音频归守望人。
2. 在编辑器的「背景音乐」中点「同步音乐文件夹」，选择整个 `music` 文件夹。新增歌曲会追加到所属歌单。已有曲目保留名称和顺序，可在相应角色下改名、排序或删除。
3. 点击「下载 site-content.js」，用下载文件替换 `assets/site-content.js`。换歌时将新音频按原路径一并上传。只调整曲名或顺序时，提交内容文件即可。

新进入首页默认使用守望人，音乐默认关闭。顶栏按顺序循环播放，点击留声机会切为当前歌单内的随机循环。换装时回到守望人的普通歌单。若正在播放专属歌单，原曲渐出，普通歌单第一首渐入。若已暂停则保持暂停，若已在普通歌单则保留当前进度。使用白色人偶时，点击右侧灰蓝色小册，前两次保持原曲，第三次应淡入她歌单的第一首。换为梦庭人偶时，改点右侧酒红色皮面书；换装会清零点击次数。浏览器阻止播放时，顶栏会显示「点击打开音乐」。点击后检查曲名和进度，同时确认留声机唱片开始转动。播放专属歌单时，从手牌进入项目、查看动态或返回首页，检查曲名和进度能接续；在项目页或动态页到达曲尾后，也应按当前歌单的顺序或随机模式继续播放。手动关闭时应显示「音乐 关」。

验收桌面牌位时，依次拖牌到己方三个空位，观察牌从松手处落到桌面，再试一次已有牌的位置和牌位外的空桌面。点牌收回后抽满五张，再点桌上的牌，检查它是否留在原位。从项目返回后核对三个牌位与手牌。放牌与收牌成功后，分别核对对应的气泡。通过古镜换成两套人偶时，核对各自的换装台词；从项目返回时确认气泡收起。台词原文以作者保存的[《幽灵语录》](幽灵语录.docx)为准。

## 保存与导出

编辑时会自动保存，也可以点击「保存草稿」。点击「预览草稿」会在新标签页打开本次修改。可分别检查首页手牌、下方的项目列表及一篇详情页。

「下载 site-content.js」会导出当前内容。将下载的文件放到仓库的 `assets/site-content.js`，连同新增素材一起提交，其他人拉取后即可看到修改。「导出整站 ZIP」适合完整备份，会包括当前草稿、网页、三维场景脚本和引用的站内媒体。带视频的压缩包较大，请等待下载完成。

「还原到网站文件版本」会用当前网站文件中的内容覆盖浏览器草稿。若想保留两个版本，可先下载内容文件。

## Git 版本与发布

互动工作稿保存在本机的 `prototype/`。通过[工作稿预览](http://127.0.0.1:8201/?scene=prototype)查看修改，确认后在项目根目录运行 `.\scripts\sync-interactive.ps1`，再从普通首页检查发布版。整站导出使用 `interactive/`。

书架的像素刻印保存在工作稿的 `prototype/art/book-prints.js`。同步后，普通首页和整站 ZIP 都从 `interactive/art/book-prints.js` 读取同一份图案。在桌面浏览器分别悬停红书和蓝书，检查深棕色夜空是否贴到各自金框的上内沿、人物是否居中，再熄灭蜡烛检查书皮上的聚光。

工作分支可用于暂存。确认发布时，提交仓库中的互动运行文件、页面、内容和 README，推送到远程 main，再核对远端提交。工作流程与互动方案的发布版放在 `docs/`，原型与实验素材留在本机。

双击本地 HTML 验收跨页音乐时，地址可能出现 `#view=`，表示项目或动态在原标签页内打开。通过网页服务访问时使用正常的页面路径。

外观更新后，按[仓库首页的桌面验收设置](../README.md#互动首页的预览与发布)打开工作稿并截图。用鼠标悬停查看完整手牌、牌堆和铃铛提示，再检查牌脚渐隐、抽满五张后放回，以及点击或拖牌进入对应作品的效果。

返回流程要在同一标签页验收。先抽第四张牌，熄灭指定的两根蜡烛，记下牌序，再打出一张并从项目页点击「返回首页」。应看到淡入过渡、剩下的三张手牌和之前的烛光，继续抽牌应从原牌库顶部抽取。再分别从动态页和浏览器后退返回一次。最后全熄灯，检查三个桌面道具的顶光，以及收牌和重抽过程中的牌面亮度。
