# 卡牌作品集首页现状

更新于 2026-11-17。卡牌首页和本说明保存在 GitHub 的 `draft/card-homepage` 分支，线上网站继续使用 `main`。在本地切到草稿分支后，预览仓库根目录的 `index.html` 可以体验完整首页。

## 首页构图

- 以电脑浏览器为主，使用 **1920 × 945** 作为桌面对照尺寸。顶部左侧显示 **PAN HOULIN**，右侧导航可以直接进入简介、作品、动态和联系方式。
- 首屏采用固定视角的工作室。木梁和灰绿色桌面使用底图，书架、画板、吊灯、植物架和小幽灵使用独立的二维素材。场景四周沿用网页的深色背景，以渐隐衔接下方内容。
- 纸质手牌采用约 **0.69:1** 的宽高比，随手牌数量展开成扇形。牌底约五分之一淡入桌面，悬停或键盘聚焦时抬起并转正，显示完整牌面和放回入口。牌面图标为当前版本占位。

## 交互

- 开局三张，手牌上限五张。点击牌库抽牌，拖回牌库或使用牌上的「放回」按钮收牌，两种操作均有过渡动画。
- 把牌拖向小幽灵或直接点击牌，会触发角色受击、文字对白和短暂转场，然后进入对应作品详情页。卡牌使用指针跟随，可用鼠标和触屏操作。
- 点击幽灵可打开简介。「回合结束」定位到首页动态区。顶部导航和「直接浏览全部作品」提供普通浏览入口。

## 素材与验证

- `prototype/art/` 存放场景和角色素材，`prototype/index.html` 是首页加载的互动区。网站编辑器导出的压缩包会带上互动区和使用中的素材。
- [假 3D 动画演示](假3D演示.html)和[拆面构图演示](拆面构图演示.html)保留了早期设计过程，可在本地单独查看。
- 已在 **1920 × 945** 浏览器视窗检查三张和五张手牌的排布、牌底渐隐和聚焦状态，并验证抽牌及键盘放回。此前在浏览器验证了出牌后进入作品详情页。实体手机上的触屏拖动和性能尚待实测。
- 下次继续时，可在草稿分支上细化牌面图标、布局和动画。确认发布后再把选定的改动合入 `main`。
