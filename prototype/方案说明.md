# 烛光木屋互动首页

首页载入 `prototype/index.html`。木屋、桌子、书架、窗外树林、烛台和正面折纸幽灵都是实时绘制的低面模型。互动区域四周融入全站的炭黑背景，烛火摇曳，近处道具随鼠标移动产生更明显的视差。牌名和状态位于底部渐隐上方。

## 操作

开局有三张作品卡，手牌上限五张。点击牌库抽牌，把牌拖回牌库或使用「放回」按钮即可收牌。点击作品卡会将它投向幽灵，也可以直接拖到幽灵身上。命中后，幽灵向后弹、镜头短震，再进入该项目详情。点击幽灵打开个人简介，「回合结束」定位到首页动态区。

普通导航与键盘操作也可访问作品。系统启用减弱动态效果时，场景停止持续晃动和火焰动画，出牌使用缩短的过渡。

## 修改位置

- `assets/site-content.js` 提供个人资料、项目、卡面图片与开发日志。日常修改可使用[内容编辑器](../editor.html)。
- `prototype/cabin-mesh.js` 构造场景和幽灵的几何形体。`prototype/cabin-view.js` 控制视角、烛光、模型回弹和镜头震动，优先使用 WebGL，亦提供软件绘制。
- `prototype/prototype.js` 管理手牌、拖放、简介和页面跳转。`prototype/prototype.css` 控制牌面布局、窄屏排列和边缘渐隐。
- `assets/site.js` 将互动区嵌入首页，根据子页面报告的实际高度调整。修改卡片高度或下缘渐隐时，请同时测试双击本地文件和通过 HTTP 浏览这两种方式。
- `assets/export-site.js` 维护整站导出的文件清单。增加必需场景脚本或装饰素材时，也要更新清单。

[假 3D 动画演示](假3D演示.html)与[拆面构图演示](拆面构图演示.html)保存了早期的设计探索。当前首页通过仓库根目录的 [index.html](../index.html) 进入。
