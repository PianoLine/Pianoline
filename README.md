# 潘厚霖的游戏设计作品集

首页是一张烛光木桌。访客可以通过桌对面的守望人和手牌浏览作品，也可以从导航直接进入项目、开发日志和联系方式。

牌桌左侧显示 `PIANOLINE`，副标题为 `Game Designer / Systems Designer`。这两行分别对应编辑器的「首页姓名」和「姓名下方的职业方向」。调整布局、交互或音频时，请保留作者在编辑器中填写的文案。

## 作品卡与牌桌玩法

- **读牌**　牌名在上，中央的项目截图以七级墨色印在米白纸底上。悬停会抬起整张牌，插图渐变为原彩封面。牌脚左侧是项目编号，右侧是项目类别。
- **抽牌与还牌**　新开或刷新首页会开始一局，随机发三张作品卡，手牌上限为五张。点击牌堆可抽一张；主动将手牌拖回牌堆，会把它插到牌库底部。桌上的牌堆最多显示十层，悬停时显示实际余牌数。
- **桌面牌位**　桌面靠近玩家的一侧有三个牌位，下方是一条带空心菱形的细横线。每格可暂放一张，桌上的牌持续显示彩色项目封面。将手牌拖到空位松开，牌会扬起亮面、短暂停顿，再扣上桌面。触桌时四角闪出金线，拍牌声后带一小段金属余音。点击桌上的牌可收回手中，手牌达到五张时留在原位。使用怀表重抽也会保留桌上的牌。
- **出牌与回合结束**　点击手牌，插画会展开，再落到项目详情的封面位置。把牌拖到幽灵身上会触发受击和翻牌转场。两种出牌都会将这张牌暂时移出本局。敲响桌铃可前往首页动态区。
- **怀表重抽**　点击怀表会合并手牌、牌库余牌和所有已用牌，洗匀后重发三张。全副牌用尽时也可以这样继续。
- **幽灵对话**　首次入场会依次播放两句问候，从项目或动态返回时气泡默认收起。点击幽灵可以随机闲聊。抽牌、洗牌、出牌、把牌放上桌或收回手中，以及切换烛光、悬停书本和点击留声机，都会触发相应台词。通过古镜换成白色人偶或梦庭人偶后，角色会从该装扮的专属台词中随机说一句。台词显示完后，气泡会按句长停留 3 至 6.5 秒再收起。完整原文和触发条件见[《幽灵语录》](docs/幽灵语录.docx)。
- **音效**　牌桌音效首次访问默认开启。如果浏览器要求先操作页面，右上角会显示「点击开启音效」，点击牌桌即可解锁。右上角可以关闭音效，浏览器会记住静音选择。抽牌、还牌、点击出牌、拖牌命中幽灵、怀表切牌和桌铃都有动作声，小幽灵随文字弹出发声，标点处停顿。
- **背景音乐**　首次进入和刷新时音乐默认关闭。浏览器拦住播放请求时，顶栏显示「点击打开音乐」，点击后重试当前曲目。顶栏显示所选曲名、播放进度和总时长。打开开关后音量渐入，关闭时渐出并暂停；暂停时也能拖动进度条，之后从选定位置继续。在同一标签页打开项目、阅读动态或返回牌桌，曲目和播放进度会接续，曲终按当前歌单继续。手动关闭后，返回首页也会保持安静。在[编辑器的背景音乐区](editor.html#playlist)中导入音频或填写音频直链，可以调整顺序和删除曲目。默认按列表顺序循环，只有一首时循环该曲。点击桌上的留声机会开始随机播放当前选用的歌单，同一音频地址每轮只播放一次。再次点击可切到本轮下一首，一轮结束后继续下一轮；多首曲目时，两轮交界也会避开刚播放的歌曲。导入本地文件后用「预览草稿」试听，「导出整站 ZIP」会包含这些音频。
- **右侧书架**　鼠标移到三本书中的一本时，书会向外探出并出现黄色描边。红书露出《血源诅咒》的满月猎人封面，蓝书露出《黑夜君临》的风暴骑士封面。屋内较暗时，光束会照在选中的书皮上。
- **烛光**　五根蜡烛都可以独立熄灭或点亮。光线变暗后，选中牌堆、怀表或铃铛会出现顶光，选中的手牌会轻微提亮。烛光会按距离和方向照亮幽灵女孩。光线变暗时，眼睛与双手泛起红光，从掌心到手腕逐渐减弱，嘴部随面部变暗。
- **返回首页**　在同一标签页从项目或动态返回，牌桌会恢复剩余手牌、三个牌位、牌库顺序、已用牌和五根蜡烛各自的亮灭。点击「返回首页」时，内容页先淡出，牌桌再从中央显现。系统开启「减少动态效果」时直接返回。

角色定稿、草图转像素、清杂色、逐帧动画制作和桌面验收流程见[《幽灵女孩动画设定》](docs/幽灵女孩动画设定.md)。

## 更新卡面和台词

在[内容编辑器](editor.html)的「项目作品」下点击「＋ 新增项目」。填写项目名称、类别和封面后，点击「预览草稿」即可查看新增作品和对应的牌。每个项目生成一张牌，缩略图留空时使用详情封面。发布编辑器导出的整站 ZIP，或更新已接入新版编辑器的网站内容文件后，新卡就会进入访客的随机牌组。

[《幽灵语录》](docs/幽灵语录.docx)保存作者提供的台词原稿。调整台词时，同步更新工作稿中的 `prototype.js` 和文档。

## 更新歌单与试听

在[背景音乐编辑器](editor.html#playlist)中先选择「守望人」「白色人偶」或「梦庭人偶」，再导入文件或添加地址。各皮肤的歌单分别保存。

新开或刷新首页时从守望人开始。从项目或动态返回当前牌局时保留所选皮肤。点击墙上的八角铜镜，会从守望人、白色人偶和梦庭人偶中等概率抽取当前装扮以外的一套。暗金色像素雾从桌沿升起，在人物完全隐去时换装。整片雾随后均匀渐淡，显出新装。换装时回到守望人的普通歌单。若正在播放专属歌单，原曲渐出，普通歌单第一首渐入。若已暂停则保持暂停，若已在普通歌单则保留当前进度。使用白色人偶时，点右侧灰蓝色小册三次，旧曲淡出，白色人偶歌单从第一首淡入。梦庭人偶以同样方式点酒红色皮面书三次，进入自己的歌单。换装会清零点击次数。留声机在当前歌单内换曲。

把新音频放进 `assets/media/music/守望人/`、`assets/media/music/白色人偶/` 或 `assets/media/music/梦庭人偶/`。在编辑器的「背景音乐」中点「同步音乐文件夹」，选择整个 `music` 文件夹。根目录的音频归守望人。同步会把新歌追加到各自歌单，保留已有曲名和顺序。移除曲目可用行内「删除」。点「下载 site-content.js」替换 `assets/site-content.js`。发布到主站时，将新增音频按原路径随内容文件一起上传。

用本机发布版试听时，打开顶栏音乐开关，点击手牌进入项目，再从首页进入「全部动态」，可检查曲目和进度是否接续。也可以双击 HTML 浏览；如果浏览器在使用后退键后暂停了音乐，点击顶栏音乐开关即可续播。

## 互动首页的预览与发布

默认在电脑浏览器中验收，以 1920 × 1080 的网页视口、100% 缩放和鼠标操作为基准。验收截图使用桌面视图，保留页面导航和整张牌桌，方便对照布局。涉及响应式布局时，再补查窄屏。

普通首页和编辑器的整站 ZIP 使用 `interactive/` 中的发布版。即使只有从 Git 下载的网站，也可以直接打开 `index.html` 浏览。

开发互动时，在项目根目录启动本机服务（例如 `python -m http.server 8201 --bind 127.0.0.1`）。下列入口分别用于预览工作稿和检查待发布版。

- [本机互动工作稿](http://127.0.0.1:8201/?scene=prototype) 读取本机的 `prototype/`。这个目录由 Git 忽略。换电脑时可复制自己的工作目录，或复制 `interactive/` 并命名为 `prototype/` 作为起点。
- [本机发布版](http://127.0.0.1:8201/) 读取 `interactive/`。在[本机编辑器](http://127.0.0.1:8201/editor.html) 中预览内容草稿和导出整站，也使用这份互动。
- 确认效果后，从项目根目录在 PowerShell 运行 `.\scripts\sync-interactive.ps1`，将运行文件同步到 `interactive/`。在普通首页验收，再将确认的发布文件和文档提交并推送到远程的 main 分支。
- [网站工作流程](docs/网站工作流程.md)记录了编辑、同步歌单与发布步骤。[互动方案说明](docs/方案说明.md)记录了牌桌规则。原型和实验素材保存在本机。

增加新的互动运行文件时，同时更新同步脚本和 `assets/export-site.js` 的文件清单。
