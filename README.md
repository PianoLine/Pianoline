# 潘厚霖的游戏设计作品集

首页是一张烛光木桌。访客可以通过折纸幽灵和手牌浏览作品，也可以从导航直接进入项目、开发日志和联系方式。

- [网站首页](index.html)
- [内容编辑器](editor.html)

## 作品卡与牌桌玩法

- **读牌**　牌名在上，中央的项目截图以七级墨色印在米白纸底上。悬停会抬起整张牌，插图渐变为原彩封面。牌脚从左到右是项目编号、与玩法对应的印记、项目类别。
- **抽牌与还牌**　新开或刷新首页会开始一局，随机发三张作品卡，手牌上限为五张。点击牌堆可抽一张；主动将手牌拖回牌堆，会把它插到牌库底部。
- **出牌与回合结束**　点击手牌，插画会展开，再落到项目详情的封面位置。把牌拖到幽灵身上会触发受击和翻牌转场。两种出牌都会将这张牌暂时移出本局。敲响桌铃可前往首页动态区。
- **怀表重抽**　点击怀表会合并手牌、牌库余牌和所有已用牌，洗匀后重发三张。全副牌用尽时也可以这样继续。
- **幽灵对话**　首次入场会依次播放两句问候，从项目返回时显示第二句。点击幽灵随机闲聊，抽牌、出牌和切换烛光也会触发台词。完整原文和触发条件见[《幽灵语录》](docs/幽灵语录.docx)。
- **音效**　牌桌右上角可开启音效，浏览器会记住此设置。抽牌、还牌、点击出牌、拖牌命中幽灵、怀表切牌和桌铃都有动作声，小幽灵随文字弹出发声，标点处停顿。
- **烛光**　五根蜡烛都可以独立熄灭或点亮。光线变暗后，选中牌堆、怀表或铃铛会出现顶光，选中的手牌会轻微提亮。全部熄灭时，窗外和幽灵的眼睛、笑脸最亮。
- **返回首页**　在同一标签页从项目或动态返回，牌桌会恢复剩余手牌、牌库顺序、已用牌和五根蜡烛各自的亮灭。点击「返回首页」时，内容页先淡出，牌桌再从中央显现。系统开启「减少动态效果」时直接返回。

## 更新卡面和台词

在[内容编辑器](editor.html)中修改项目标题、类别、卡牌缩略图和详情封面。卡牌缩略图留空时使用详情封面。牌脚印记按项目 ID 对应，新项目默认使用罗盘印记。印记图集位于 [project-stamps.png](interactive/art/project-stamps.png)。

[《幽灵语录》](docs/幽灵语录.docx)保存作者提供的台词原稿。调整台词时，同步更新工作稿中的 `prototype.js` 和文档；默认的返回问候写在工作稿的 `index.html` 中。

## 互动首页的预览与发布

默认在电脑浏览器中验收，以 1920 × 1080 的网页视口、100% 缩放和鼠标操作为基准。验收截图使用桌面视图，保留页面导航和整张牌桌，方便对照布局。涉及响应式布局时，再补查窄屏。

普通首页和编辑器的整站 ZIP 使用 `interactive/` 中的发布版。即使只有从 Git 下载的网站，也可以直接打开 `index.html` 浏览。

开发互动时，在项目根目录启动本机服务（例如 `python -m http.server 8201 --bind 127.0.0.1`）。下列入口分别用于预览工作稿和检查待发布版。

- [本机互动工作稿](http://127.0.0.1:8201/?scene=prototype) 读取本机的 `prototype/`。这个目录由 Git 忽略。换电脑时可复制自己的工作目录，或复制 `interactive/` 并命名为 `prototype/` 作为起点。
- [本机发布版](http://127.0.0.1:8201/) 读取 `interactive/`。在[本机编辑器](http://127.0.0.1:8201/editor.html) 中预览内容草稿和导出整站，也使用这份互动。
- 确认效果后，从项目根目录在 PowerShell 运行 `.\scripts\sync-interactive.ps1`，将运行文件同步到 `interactive/`。在普通首页验收，再将确认的发布文件和文档提交并推送到远程的 main 分支。
- 本机工作目录里的《方案说明》和《网站工作流程》记录了操作规则及编辑步骤。实验稿与维护笔记只保存在本机。

增加新的互动运行文件时，同时更新同步脚本和 `assets/export-site.js` 的文件清单。
